Abhi download karna hai?

Neeche kisi bhi service par tap karein — aap ka link khud copy ho jayega aur wo site khul jayegi. Wahan sirf paste karna hai.

Ye teesri parties ki sites hain — inke apne ads aur qawaid hain, hamara control nahi. Apna server chalne par ye hissa gayab ho jayega.

📱 Phone se chalana hai

Phone par yt-dlp chal nahi sakta, to server kahin aur hona chahiye. Do options:

A · Same WiFi par computer: computer par server chalayein, wo start hote hi apna network address print karta hai (jaise http://192.168.1.5:8080). Wohi address phone ke browser me kholein — page aur API dono wahin se aayenge, kuch connect karne ki zarurat nahi.

B · Kahin se bhi: backend ko Render/Railway par free deploy karein (DEPLOY.md me 5-minute guide hai), phir us https://… URL ko upar wale box me daal kar Connect dabayein. Ek dafa set — hamesha yaad rahega.

Note: ye page HTTPS par hai, is liye yahan sirf https:// API chalegi. LAN wala http:// address seedha phone ke browser me kholein (option A).

💻 Computer par chalana hai 
cd sss-backend
node server-nodeps.js

Phir http://localhost:8080 kholein — server khud ye page serve karta hai, API apne aap connect ho jati hai.
